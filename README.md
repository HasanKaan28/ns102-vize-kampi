# NS102 Vize Kampı

A single-page study site for the NS102 Physics midterm (IUS, Fall 2026), written in Turkish.

**Live site:** https://hasankaan28.github.io/ns102-vize-kampi/

## What is inside

- **Soru çöz (practice):** one question at a time, exam-sheet style, with a filter rail and a question map.
  - Part C: 71 problems modelled on the end-of-chapter exercises of Young & Freedman, *University Physics* 15e (Global Edition), chapters 2–7. Each problem is rewritten with new numbers; the book's exercise number is shown on the card. Answers are checked with a 2% tolerance and every answer was computed in Python.
  - Part B: 119 conceptual questions restated from the chapters' discussion questions, with model answers.
  - Part A: 99 multiple-choice questions, one per chapter 1–6 clicker slide, written in original wording with original options; after answering, the slide's correct letter is shown too.
  - Figure-based questions come with original SVG drawings (55 figures); no textbook or slide images are used.
- **Sınav analizi:** structure of last year's midterm and worked solutions.
- **Konu anlatımı:** short topic notes for chapters 1–7.
- **Çalışma planı** and **Udemy Pro** study tips.

Progress, notes and checked tasks are stored only in the visitor's browser (`localStorage`).

## Notes

- No textbook or slide text is reproduced; problems use new numbers and the conceptual questions are written in original wording.
- The page asks search engines not to index it (`noindex`).
- It is a static site: `index.html` only, served by GitHub Pages from the `main` branch.
